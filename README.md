# NCRN Annual water quality summary

## Get Started

You need three things:
1) R and R Studio
2) The code in this repository
3) Inputs

### R and R Studio
Download and install these from company portal. Note that R is called "R-Project".

### The code in this repository
1. Open R Studio
2. File -> New project
3. Create Project from Version Control
4. Choose Git
5. `Repository URL`: https://github.com/NCRN/Water_Quality_Annual_Summary
6. Keep the `Project Directory Name` "Water_Quality_Annual_Summary" unless you have a reason to change it
7. `Create Project as a subdirectory of`: Choose a local folder. E.g., 'C:/Repos'
8. Click `Create Project`

### Inputs
You need:
1) data and metadata
  - In your project directory, create a folder called `data`
  - Download the latest [data package files](https://irma.nps.gov/DataStore/Reference/Profile/2317661) into your `data` folder
2) site images
  - In your project directory, create a folder called `Site images`
  - Download the images from [this folder](https://doimspp.sharepoint.com/:f:/r/sites/NCRNWater/Shared%20Documents/13_REPORTS/IARs/2025/version1/Water_Quality_Annual_Summary/Site%20images?csf=1&web=1&e=3kxn3m) into your `Site images` folder

## Run the program
- In R Studio, open the file named `wq_summary_generator.R` and then step through the script
